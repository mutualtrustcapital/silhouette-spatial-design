# Silhouette Spatial Design — website

Static website for **Silhouette Spatial Design** (Mannat Khurana), an interior design studio based in Auckland, working across New Zealand and Australia.

- `gh-pages` branch: the current **review copy** of the site, published with GitHub Pages. Every page carries `noindex`, so search engines will not list this copy.
- The launch version will be served from **silhouettespatialdesign.com** (Netlify). That build uses clean URLs, Netlify Forms, security headers, a sitemap and `robots.txt`.

Content, copy and images belong to Silhouette Spatial Design. Drawings marked "illustrative" are concept sketches, not records of completed projects.
